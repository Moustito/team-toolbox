## How to run

Type python main.py in your command line interface

## Tools

### Temperature Converter

Converts temperature from Fahrenheit to Celsius and vice versa

### Number Guessing Game

A game when you have to guess a number the machine think of.
You have 7 tries.

### Grades

A logiciel that saves your notes and returns you stats about these: average, lowest note, highest note and a litte word about it.
